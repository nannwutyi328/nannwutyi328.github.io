JS Method: addEventListener

It is used to attach an event handler to an HTML element without overwriting existing handlers.

Syntax: element.addEventListener(event,callback function,options)

Event and Description

click
-user clicks an element
dblclick
-user double-clicks an element
mouseover
-mouse moves over an element
mouseout
-mouse leave an element
mouseenter
-mouse enters an element
keydown
-key is pressed
keyup
-key is released
submit
-form is submmited
