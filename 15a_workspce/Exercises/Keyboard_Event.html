Keyboard Events

Event Description
keydown Fires when the user presses a key on the keyboard
keyUp Fires when the user releases a key on the keyboard.
keypress Fires when the user presses and bolds a key on the keyboard.

Keyup Event

The keyup event is triggered when a key is released after being pressed.It allows you to capture the key that was released and perform actions based on that key.

Keydown Event

The keydown event is triggered when a key is pressed down. It allows you to capture the key that was pressed and perform actions based on that key.

Keypress Event

The keypress event is triggered when a key is pressed and down. It allows you to capture the key that was pressed and perform actions based on that key.
