There are transitions for the following properties:

  • transition-property is used to specify thename of the CSS property to which the transition is applied.
  • transition-duration specifies the durationof the transition.
  • transition-timing-function defines the speed curveof the transition.

    Common values incluse: linearis used to specify a constant speed, easeis used to sepecify a slow start and end, ease-inis used to specify a slow start, ease-outis used to specify a slow end, ease-in-outis used to specify a slow start and end.

  • transition-delay specifies a delay (in seconds or milliseconds)before the transition starts.
